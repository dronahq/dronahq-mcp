# Security

This repository holds documentation and client configuration only. The DronaHQ MCP server runs inside DronaHQ Studio, so a vulnerability in the server should be reported to DronaHQ directly, not filed as a public issue.

Email **inquiries@dronahq.com** with the subject "Security", the affected Studio host (cloud or self-hosted), and steps to reproduce. Do not include real credentials or customer data.

See [Security and governance](README.md#security-and-governance) for how credentials, tokens, and permissions are handled.
